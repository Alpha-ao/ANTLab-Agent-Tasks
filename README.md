# 文档问答与故障诊断

基于 [ANTLab Agent Tasks](https://github.com/Shiina413/ANTLab-Agent-Tasks) 的文档问答与故障修复项目。仓库包含基础问答实验、B 题样机修复、交互页面，以及可供核对的原始输入、模型回答和测试记录。

项目关注两个问题：资料顺序和选择方式怎样影响回答；程序出现旧结果、漏检索或错误验证状态时，怎样找到原因并验证修复。

## 项目内容

| 模块 | 做了什么 | 阅读入口 |
|---|---|---|
| 基础任务 | 根据资料回答问题并给出引用，比较资料换序、筛选和提示词调整后的结果 | [任务说明](基础任务/README.md) · [报告](基础任务/报告.md) |
| B 题 | 复现并修复缓存、范围筛选和引用状态问题，用对照实验区分故障原因 | [任务说明](B任务/README.md) · [报告](B任务/报告.md) |

基础页面支持查看问题、回答、引用原文和历史请求。B 题页面支持对照原版与修复版，检查版本切换、证据结果和验证状态。

## 主要结果

- **基础问答**：首轮 8 道评测题中，原顺序暂定答对 4 道，排序改进答对 3 道，未带来提升。后续调整提示词并开启思考模式，完整资料的四组实验均为 8/8。后续实验使用了已见题目和更多推理预算，不能归因于排序，也不属于独立盲测。
- **故障修复**：修正缓存未区分资料版本、先截取后筛选导致漏检索，以及把引用可定位当作内容已验证的问题。39 项行为检查和 12 项同症状对照检查通过，具体输入和输出保留在仓库中。
- **模型诊断**：保留 3 类故障、3 种信息条件下的 9 次模型回答，用于观察外部信息怎样影响诊断。这部分没有测试模型自动修改代码，不能作为自动修复成功率。

详细结果见[整合报告](report.md)、[基础逐题结果](基础任务/结果/)和[B 题逐例说明](B任务/结果/逐例说明.md)。

## 快速开始

需要 Python 3.10 或以上版本，运行代码仅使用标准库，无需安装第三方依赖。

```bash
git clone https://github.com/Alpha-ao/ANTLab-Agent-Tasks.git
cd ANTLab-Agent-Tasks

# 启动基础问答页面
python 基础任务/运行.py

# 或启动 B 题对照页面
python B任务/运行.py
```

启动后，在浏览器中打开终端提示的访问地址。页面需自行运行，仓库未提供在线托管演示。默认查看已保存的模型回答或执行样机程序，不调用付费 API。

## 测试与结果复算

在仓库根目录执行：

```bash
# 单元测试
python -m unittest discover -s tests -v

# 根据已保存的回答复算基础任务结果
python scripts/score_exploration.py

# 核对分类副本与原文件
python scripts/organize_results.py --check
```

重新执行 B 题行为检查：

```bash
python scripts/check_advanced_b.py --label review_01
python scripts/check_b_same_symptom.py --label same_review_01
```

每次使用未占用的记录名称，避免覆盖已有实验。以上命令均不调用模型 API。重新进行真实模型实验需要自行配置服务与密钥，并承担相应费用；调用方式见各任务文档。

## 目录

| 目录 | 内容 |
|---|---|
| `基础任务/`、`B任务/` | 分类报告、结果、资料和代码索引 |
| `基础/`、`进阶/` | 原题、数据与实现代码 |
| `scripts/`、`web/`、`tests/` | 运行脚本、交互页面与测试 |
| `runs/` | 实验输入、原始响应和故障记录 |
| `configs/`、`versions/` | 实验配置与原版代码存档 |
| `results/` | 逐题评价、汇总和费用记录 |

分类目录中的结果是便于阅读的副本，来源见各目录的 `文件来源.json`。更新结果后，可运行 `python scripts/organize_results.py` 同步副本。文本校验只统一换行符，不忽略其他内容差异。

## 已知限制

答案判分尚无独立人工复核；引用编号存在不代表原文支持回答。B 题修复版明确区分引用定位与内容支持，未完成语义核验时保留未核验状态。现有检查覆盖题包和补充案例，不代表通用文档问答能力或生产环境可靠性；多用户和多进程部署尚未验证。
